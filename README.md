# nbu-mle-rates

Мини-набор скриптов, которые показывают в консоли официальные цены LME на металлы
и курсы валют НБУ. Без зависимостей: только стандартная библиотека Python либо
встроенный в Windows PowerShell.

## Файлы

| Файл | Что делает |
| --- | --- |
| `rates.cmd` | Всё сразу: LME + НБУ. PowerShell, запускается двойным кликом в Windows |
| `rates.py` | То же самое на Python |
| `lme_rates.py` | Только цены LME |
| `nbu_rates.py` | Только курсы НБУ |

## Запуск

**Windows, без Python** — дважды кликнуть на `rates.cmd`. Окно закроется само
через 10 секунд после вывода (или по нажатию любой клавиши).

**Python 3.6+**, любая ОС:

```bash
python rates.py
```

## Источники данных

- **LME** — [westmetall.com](https://www.westmetall.com/en/markdaten.php), таблица
  «Official LME-Prices» разбирается регулярными выражениями. Публичного API нет,
  поэтому при изменении вёрстки сайта парсинг придётся поправить.
- **НБУ** — [официальный JSON-API](https://bank.gov.ua/NBUStatService/v1/statdirectory/exchange?json).
  Валюты по умолчанию: USD, EUR, XAU (золото), XAG (серебро) — список задаётся
  константой в начале скрипта.

## Как устроен `rates.cmd`

Файл-полиглот: первые строки — обычный батник, всё после маркера `#PSCODE` —
код PowerShell. Батник читает сам себя и передаёт хвост файла в PowerShell,
поэтому логика лежит в одном файле и остаётся читаемой.
